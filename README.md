## Como executar

1. Rodar requirements: 

pip install -r requirements.txt

2. Instalar uvicorn:

pip install uvicorn

3. Iniciar API:

python -m uvicorn api:app --reload

4. Baixar n8n: 

npm install n8n -g

5. Executar no terminal: 

n8n start

6. Acessar: 

O n8n ficará disponível em:
http://localhost:5678

7. Baixar o arquivo "Hill Climbing Correto.json" , importar no n8n e Executar

8. Baixar o arquivo JSON gerado e colocar na pasta "resultados": 

resultados/

9. Rodar análise:

python analise.py
